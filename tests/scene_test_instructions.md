# Instructions for how to create a Playwright test for a specific scene.

1. Use jj to create a new worktree of /usr/local/google/home/swansonjeremy/santa/santa-tracker-web under /usr/local/google/home/swansonjeremy/santa/santa-tracker-web-worktrees. E.g. /usr/local/google/home/swansonjeremy/santa/santa-tracker-web-worktrees/santa-tracker-web-SCENE. The name of the worktree should match the name of the scene. Run ALL subsequent commands within that worktree.
2. Follow instructions in tests/game_test_instructions.md. When running tests, only run the new tests being created, not the existing tests.

Note: Other agents will be working on the same task for other scenes at the same time.
